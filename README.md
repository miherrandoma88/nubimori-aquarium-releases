# Nubimori Aquarium · Descargas

Versiones públicas para Android y Windows.

- [Abrir la app web](https://nubimori-studios.vercel.app/aquarium/?lang=es)
- [Elegir una versión](https://nubimori-studios.vercel.app/aquarium/versions/?lang=es)
- [Archivos de la versión 0.8.0-dev](https://github.com/miherrandoma88/nubimori-aquarium-releases/releases/tag/v0.8.0-dev)

Android connected permite la cuenta y sincronización opcionales. Android offline funciona sin permiso de Internet y conserva las transferencias manuales cifradas. Windows x64 es portable: descomprime el ZIP y abre `Windows/NubimoriAquarium.exe`, conservando la carpeta completa.

La versión 0.8 es una compilación de desarrollo y no recupera la firma original de distribución. Conserva una copia de tus datos antes de actualizar. Las huellas SHA-256 se incluyen con cada publicación.

124 fichas con pixel art original, 22 idiomas, planificador de comunidad, historial de agua y cuidados, equipo y gastos, cuarentena y fotografías. La sincronización automática requiere activación y funciona con la app abierta y desbloqueada.
